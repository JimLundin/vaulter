# Grouped settings

The selected design uses grouped cards with direct choices for Chat model, Voice and Theme.
Run limits, transcription models and retries use validated selectors with Custom entry. Instructions
and API URLs remain text. Preferences use the owning module's device store; credentials use the
Session's encrypted overrides. Scoped resets retain other settings.

OpenAI endpoint changes apply to subsequent capabilities and survive reload. GitHub endpoint
changes validate the candidate journal before saving and replacing the active adapter; rejected
connections keep the active Vault and preference intact. Endpoint URLs are ordinary device preferences,
never credentials or Vault records. The build permits HTTP(S) and WebSocket connections so explicitly
configured compatible services can be reached; scripts remain restricted to this installation.

The preview comparison now retains one mounted Application and frame. Its only alternatives are
Grouped cards and Grouped cards with compact spacing; variant changes update presentation in place.
The earlier three-layout prototype is retained in git history at `d5b1d45`.
