Rechecked from integration `5f1036e` before implementation. Decisions follow the
[#20 agent brief](https://github.com/JimLundin/vaulter/issues/20#issuecomment-6097442566)
and approved maintainer inventory; current usage did not authorize extra public removals.

| Design/capability | Rechecked consumer evidence | Planned purpose | Decision and reason |
|---|---|---|---|

| MobileFrame and reserved notice row | Only Base frames catalogue rendered it; that example supplied no notice | Old reserved notice row above phone controls | Remove the alternate shell, notice-row layout, export and example. Shared assets: `useLayout` and `useViewport` remain needed by WorkspaceFrame and other retained
controls; shared Page/layout primitives, button/icon styles, presentation-policy providers and
Base UI Drawer remain used. The retained adaptive wide-panel rule also uses a 26rem width;
that rule is part of responsive SupportingDrawer and is preserved. Remove only the orphaned
bounded `.h-dvh` override formerly reached by MobileFrame; `.h-svh` remains used by Sidebar.
No package or token is removed. Removed shells had their dedicated styling inline, removed with
the implementations. No obsolete interaction test directly consumed the removed shells.

TDD uses the accepted public-export/catalogue policy seam: the cleanup contract initially failed
because all three retired exports remained, then passed after implementation. Existing retained
public browser seams verify drafts/focus through resize, wide/modal placement, nested dismissal,
independent paired content, touch swipe and workspace navigation.

coverage passes across phone/desktop/touch desktop for retained Agent drafts through responsive
