and approved maintainer inventory.

Shared dependencies: maplibre-gl and its transitive worker/rendering packages remain; theme hooks,
cn, map touch targets and map-control/attribution CSS remain required. No shared token, chart,
public map option or other source-unused package is removed.

Implementation: package-lock-only uninstall preserved shared node_modules. npm also normalized
unrelated bundled optional-package metadata; those unrelated edits were removed, leaving only
the approved root dependency and package records removed. @types/geojson stays because MapLibre
and other retained dependencies require it. Historical PLAN-browser-app remains historical.

Real resize verification found that changing md to sm resized the canvas but left the camera
framing at the old height, clipping outer markers. A dimension-change-only ResizeObserver now
calls MapLibre.resize and refits current supplied points/routes; selection/theme rerenders do
not recenter a user-panned map. The marker-bounds regression failed before this fix and passes
through the public MapView/catalogue seam afterward. A retained browser test explicitly opts
into real external tiles with VAULTER_MAP_TILES=1; normal suite runs skip it and Load map remains
the catalogue's network boundary. The map sample gets a 640px bounded canvas to show fill sizing.

Visual/interaction acceptance: actual MapLibre canvas, three numbered category markers and solid
and dashed routes render in both desktop and phone canvases. Screenshots reviewed for dark md,
dark compact and phone light fill; eight size/theme captures record md=256px, sm=132px, fill
using available space, bounds, selected-place callback and themed control colours. Real styles,
sprites, vector/glyph tiles returned 200 (32 responses), with no page errors. Four ERR_ABORTED
requests occurred during changing zoom/style; replacement resources loaded and screenshots show
actual dark/light maps. External OpenFreeMap style warnings (missing optional wood-pattern and
null highway-shield filter values) do not prevent the reviewed map/route rendering. No external
outage limited this acceptance. Compact strips can show closely spaced marker targets at the
lower zoom while keeping them inside the map; that existing dense-map interaction is retained.

Validation: typecheck, changed-source Biome (existing advisory messages), eight catalogue/layout
policy tests, explicit no-external-before-Load-map check, eight real size/theme captures and the
retained opt-in public marker-bounds/selection/theme browser regression pass. Root supplies full
integration suite/build/Product visual acceptance; Product currently has no map consumer.
