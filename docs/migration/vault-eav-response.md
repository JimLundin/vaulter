## Remaining private verification and separate work

- Source originals, revisions and exact source-to-native correspondence receipts.
  Equal text/URLs do not establish identity. Preserve external selections where
  native correspondence is not verified.
- Private classification provider accuracy and captured Query selections at
  explicit source/native cutoffs. Native candidate edges must not substitute for
  the original renderer's effective kind/tag classification.
- Exhaustive ordered chronology membership/child-state verification, including
  child-only edits and deleted parent selections. Calendar's current precision
  covers the audited chronology scope; no precision extension is a blocker.
- Verify integrated contribution metadata commit `7f006e8` through final
  follow-up CI, including exact input JSON/model/usage/precision.
  Separately verified structural input associations belong to Sources.
- Focused checks and commit-specific CI for the follow-up branch are pending.
  Initial merged capabilities have prior passing CI; it does not verify this work.
- Merge interaction, direct route adapters and new collection authoring UI remain
  separate from the current retained model/reader basis.

Application contracts and synthetic reopened fixtures provide no private inventory
conversion credit. Exhaustive source-backed verification and journal publication
remain the private migration's responsibility.
