# Adopt native EAV Questions with retained answer evidence

Questions adopts the Question/Answer contract of the knowledge-model proposal through the typed
EAV journal. Application composes its registry with Chat, Wiki, Graph, sources and Evidence.
Question records retain wording, proposals, availability and explicit open/answered/abandoned state.
Independent ordered context records address subjects, grounding and unresolved reviews by accepted
historical references. A subject reuses its owning identity; asking a question creates neither a
Subject duplicate nor a broad Topic.

Only trusted Agent actions create questions. Only a trusted person records direct answers or
abandons an open question. Answer admission atomically records the response, the exact question
version answered and answered state. Stale wording and competing responses reject through EAV
transaction admission. Suggestions remain editable proposals until the person explicitly submits.
Answering a review-linked question supplies evidence without changing that review or certifying
other assertions. Retained source and answer text remain readable after edits or removal.

Questions reading, writes and Agent tools use EAV exclusively. The Questions UI and session task
owner retain per-choice drafts, dictation, duplicate protection and exact-save recovery. Uncertain
publications retain SaveError.retry and never reconstruct another Answer. Context and attribution
use accepted historical EAV addresses throughout the public model.

Automatic review routing and a combined review queue remain later work.
