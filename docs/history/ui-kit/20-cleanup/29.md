Shared dependencies: Base UI ToggleGroup/Toggle remain required by pressed-choice behavior;
cn and field-association remain used. The old local style context and class-variance helper usage
were specific to rejected group alternatives; no package is removed because other kit controls
still use class-variance-authority. No public standalone Toggle exists to retire.

TDD seam: existing public controls browser fixture. Before implementation the new retained-default
outline check failed (0px border instead of 1px); after implementation it passes with original
single/multiple callbacks and arrow/Space activation. Joined geometry and shared borders are
visible through the same public seam. Nested Overlay/touch fixtures remain useful after migrating
small presentation, and SettingField keeps its unsupported-control checks.

Validation passed: typecheck; changed-source Biome (existing advisories); 52 focused Vitest tests
covering SettingField diagnostics and catalogue/layout policy; three-project controlled/default
