# Agent instructions

## Agent skills

### Issue tracker

Specs and tickets live in GitHub Issues for `JimLundin/vaulter`. Before reading or publishing
issues, follow [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Use the five default triage labels. Before classifying or labelling issues, read
[docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

This is a single-context repo. Before exploring domain behavior or designing changes, follow
[docs/agents/domain.md](docs/agents/domain.md).

### Testing

Full-suite verification runs only in CI. Run focused checks locally, then push the feature branch
and inspect its commit's CI results.
Before choosing checks for an edit or final delivery, follow
[docs/agents/testing.md](docs/agents/testing.md).
